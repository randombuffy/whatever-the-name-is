# 12 Nov 2026 — Spaceship, shared booster, surface ascent

Mission Control already judges mass, power, link, cost, and a patched-conic cruise. The hangar still looked like a small satellite, and Launch jumped from a countdown into that satellite already in space. This pass makes the craft a named spaceship, keeps one booster for every liftoff, and flies that stack from the pad with captain controls and a spoken callout loop.

## A. What Shipwright actually is

`reference/shipwright` (Dolf Veenvliet / macouno) generates a ship from a name. `js/ship.js` is not a runtime modeller. It stores authored hull chunks (vertices, quad faces, connector frames). A seed picks one chunk. The page then shows a white mesh with hard edges.

We do not paste that vertex dump into the bundle. The old `THREE.Geometry` / `Face4` API is gone, and the file is a parts catalog rather than the engineering model this game already runs. The behaviour we take is the one players notice: a call sign picks a hull, the hull is a stack of hard-edged blocks, panel lines stay on, and wings, cockpit, and engines change with the name. Credit stays on the credits screen.

Sketchfab GLBs are still welcome later in `public/models/`. Nothing in the repo is a GLB today, so this pass stays procedural and does not pretend a download happened.

## B. Call sign

The design screen already renames the craft as you type and can rebuild the part list from that string (`assembleFromCallSign`). The mesh now uses the same string. Renaming regenerates the hull. The fitted parts stay the engineering source of mass, thrust, power, and link. The hull does not invent new delta-v.

## C. Spaceship mesh

`src/render/shipwright.ts` builds the body:

- A long fuselage, nose, cockpit glass, dorsal spine, and aft bay.
- Wings and tail fins. More solar arrays stretch the wings.
- Engine housings. The count follows the main engines already fitted.
- Seeded greebles: vents, rails, blisters, a mast. The same name always rebuilds the same blocks.
- White panels, dark edge lines left visible (the Shipwright read), cockpit glass dark.

Fitted parts stay pickable and nudgeable. Each one is a smaller module on the hull, tinted by subsystem:

| Subsystem | Colour |
| --- | --- |
| Structure | bone |
| Propulsion | copper |
| Fuel | amber |
| Power | green |
| Communications | blue |
| Science | violet |
| Thermal | heat |
| Avionics | steel blue |

In the hangar, each module carries its part name. Selecting one still draws the existing selection frame.

The old bus box is no longer the body. A thin dorsal plate remains so the bus can still be selected. Tanks, bells, arrays, dishes, and instruments stay, scaled onto the ship.

## D. One booster, many ships

Every launch uses the same stack, built once in the scene:

- Core stage, white, panel lines, fixed proportions.
- A two-piece fairing around the ship.
- A pad tower and the existing ring, visible only while the stack is still low.

The ship inside is the named craft. After fairing separation the ship is the vehicle you see. After booster separation the core falls away and the ship continues. The booster geometry does not change with the mission or the call sign.

## E. Ascent physics

`src/domain/ascent.ts` is a point-mass booster in SI units. It does not replace the cruise simulation. It runs from the pad until insertion, then `commitLaunch()` hands the same craft to the existing flight sim.

State: time, altitude, downrange, speed, flight-path angle, booster propellant, dynamic pressure, Mach, mass, throttle, yaw (visual), phase, fairing, booster, abort.

Forces each step:

- Thrust along the flight path. Sea-level-class core: 8.4 MN, 311 s, 20 t dry, 430 t propellant, plus the craft’s own mass as payload.
- Weight from `G0`.
- Drag from an exponential atmosphere (`rho = 1.225 exp(-h/8500)`), `q = ½ ρ v²`, `D = q Cd A` with Cd 0.32 and area 10.5 m².
- Propellant flow `thrust / (Isp · g)`.

Guidance:

- Hold vertical until the stack has left the tower.
- A pitch program lowers the flight-path angle with altitude (gravity turn).
- Captain pitch adds or removes up to about 0.4 rad from that target. The angle moves toward the target at a limited rate.
- Captain yaw only yaws the mesh. The ascent stays in a plane.
- Throttle scales thrust. Below the weight on the pad, the stack stays down (ignition).
- Diving into the ground after liftoff, or cutting thrust too early and falling, aborts.

Phases, in order, each announced once: ignition, liftoff, max-q, fairing, booster, orbit. Orbit requires altitude above 140 km, speed above 7.6 km/s, and a flight path near the horizon. Sim time runs at 6× real time so the burn is a captain’s sequence rather than a ten-minute wait. The equations themselves stay in seconds.

This is a teaching model: one stage, no wind, no rotating Earth, no engine-out. The cruise after insertion is still the patched-conic sim.

## F. Captain controls

The launch screen keeps the hard-constraint gate and the 10-to-1 countdown. At zero it does not cut to cruise. It starts the ascent and shows:

- Altitude, speed, flight-path angle, dynamic pressure, Mach, propellant, phase.
- Throttle and pitch sliders.
- Yaw buttons.
- Abort, which returns to design.

The 3D view sits on a large Earth. The camera follows the stack once it is off the tower. The fairing opens at the fairing call. The core drops away at booster cutoff. Countdown charge still lights the pad before the clock hits zero.

## G. Voice

`src/ui/voice.ts` uses `speechSynthesis`. No extra service and no audio file. Pitch is low and rate is slightly slow so it reads as a console, not a narrator. If the browser exposes a male English voice (David, Daniel, Alex, Fred, Aaron), that voice is preferred.

Lines: each countdown number, liftoff, max dynamic pressure, fairing separation, booster separation, orbit insertion, abort. Speech follows the existing sound toggle. Reduced motion does not silence the console; mute does.

## H. What stays

Catalog ids, mass, power, link, thermal, reliability, and cruise stepping stay on the engineering path. Tests in `engine.test.ts` still cover that path. `ascent.test.ts` checks that a full-throttle gravity turn climbs, burns propellant, and reaches the insertion gate without NaNs.
